# מסמכי אפיון — WebForge

זהו המאגר המרכזי לכל האפיונים שעל פיהם נבנה אתרי דמו ותבניות לשיווק.

```text
specifications/
├── README.md              # אינדקס וכללי עבודה
├── sites/                 # מסמך אפיון נפרד לכל אתר שנותח
│   └── bucks-sauce.md
└── templates/             # תבניות כלליות שנחלץ ממספר אתרים
```

## כללים

1. כל קישור שננתח מקבל קובץ עצמאי בתוך `sites/`, למשל `boutique-hotel.md`.
2. אחרי שנמצאים כמה אתרים מאותו תחום, ניצור תבנית כללית בתוך `templates/`, למשל `food-brand-commerce.md`.
3. בכל מסמך: מקור, מבנה, סגנון, רכיבים חוזרים, משתנים ללקוח ו־checklist לבנייה.
4. האפיונים משמשים ליצירת אתרים מקוריים של WebForge, לא להעתקת נכסים או עיצובים קיימים.
