# Membership Tier Comparison

## Build

1. Limit the first view to 3–5 tiers.
2. For every tier show name, audience fit, price or “custom”, three to five benefits and one CTA.
3. Use the same benefit grammar across all tiers so differences scan quickly.
4. Highlight one recommended tier only when there is a real default for most buyers.

## Responsive behavior

- Desktop: comparable columns with equal visual weight.
- Mobile: a vertical stack; keep every CTA visible without expanding an accordion.
- If there are more than five tiers, group them by audience before comparing.

## Guardrails

- Do not hide mandatory fees, billing cadence or qualification requirements.
- Do not overload cards with long feature lists.
- Use color only as supporting hierarchy, never as the sole difference.

## Validate

- A visitor can identify their tier, price model and next action without reading every card.
- The comparison remains readable at 320px wide.
