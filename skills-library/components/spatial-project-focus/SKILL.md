# Spatial Project Focus

## Use when

A gallery needs a premium technological focal point without adding panels, gradients, buttons or decorative clutter.

## Build pattern

1. Apply the effect only to the active card.
2. Use a 1px cool-toned border, a very soft outer glow and one small light point.
3. Animate a single translucent reflection across the card when it becomes active.
4. On fine-pointer screens, apply at most 2–3 degrees of camera tilt to the active card.
5. Reset the tilt on pointer leave and disable it for reduced motion and touch-only devices.

## Guardrails

- Keep the card content readable without the effect.
- Use one accent hue only.
- Never use continuous heavy glow, particles or multiple competing animations.
- Confirm that mobile remains a static, legible card with the frame intact.
