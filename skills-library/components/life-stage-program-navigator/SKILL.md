# Life Stage Program Navigator

## Build

1. Define 3–6 mutually clear program paths.
2. Give each path a title, audience, one-line outcome, image and destination.
3. Render each path as one large clickable card; do not require a separate button.
4. Follow the navigator with the active program’s process and a low-friction CTA.

## Use a different axis when needed

- Age or life stage: therapy, education, care.
- Need: financial services, legal, consulting.
- Experience level: training, courses, SaaS onboarding.
- Business type: B2B services and platforms.

## Guardrails

- Keep one primary classification axis per navigator.
- Avoid overlapping labels that leave visitors unsure where they belong.
- Preserve the cards as a vertical stack on mobile.
- Use inclusive language and avoid unsupported outcomes or eligibility claims.

## Validate

- A first-time visitor can choose a relevant path in under ten seconds.
- Every path has an obvious next page or CTA.
- Keyboard focus and touch targets work on all cards.
